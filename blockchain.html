🔐 How Blockchain Vote Protection Works

Every successfully submitted vote creates a blockchain block containing a hashed voter identity, selected candidate, timestamp, previous block hash and its own SHA-256 block hash.

Each block is linked to the previous block through its hash. If information inside an existing block is modified, its calculated hash changes and the verification system can detect the inconsistency.

🛡️ This provides an additional integrity layer for the voting records stored by the application.
